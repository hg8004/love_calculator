# 두근두근 인연 해 계산기 · DUGEUN DUGEUN LOVE CALCULATOR

> 나의 인연은 언제 찾아올까요? — 사주팔자로 알아보는 나의 연애 성향과 인연의 시기

생년월일시로 사주 원국을 **독립 만세력 엔진으로 계산**하고, 원국 구조를 근거로 **이성 인연이 찾아올 시기**를 짚어 주는 웹사이트입니다. 부가로 나의 연애 스타일, 만나게 될 이성의 모습(외형·성격·하는 일·나이 차), 조언을 함께 알려 줍니다.

- **핵심은 인연의 시기**: 인연이 찾아올 가능성이 높은 **가장 빠른 달**과, 그 인연을 진중하게 봐도 될지 스쳐 가는 인연인지를 맨 위에 보여 줍니다.
- **사주를 몰라도 읽히는 말투**: "사주에 ○○가 있어 ○○한 사람이 잘 맞아요/끌려요!"처럼 원국 글자를 사람의 모습으로 풀어 씁니다. 명리 용어와 근거는 '자세히 보기'에 접어 둡니다.
- 모든 해석에는 근거(원국 위치·천간·지지·십성·운·합충형파해)가 함께 있으며, 가능성 표시는 확률이 아닌 **같은 사람의 시기끼리 비교한 상대적 흐름**입니다.

## 화면 흐름

1. **랜딩** — 사이트 이름, 한 줄 소개, "내 사주 보기", 기록이 있으면 "내 기록 보기"
2. **단계별 입력 (1/4 ~ 4/4)** — ① 이름(선택)·성별 ② 양력/음력(평달/윤달)·생년월일 ③ 태어난 시간(모름 가능) ④ 태어난 곳(기본 서울)·계산 기준(접힘). 빈 값이면 다음으로 넘어가지 않고 안내. 서버 검증 오류(예: 없는 윤달)는 해당 단계로 되돌려 안내. 브라우저 뒤로가기 지원(URL 해시)
3. **분석 중** — 오행 다섯 점 애니메이션 + "기운을 읽는 중…" (최소 1.5초)
4. **결과 (카드형 세로 스크롤)**
   - 요약: 이름, 출생 정보, **인연이 찾아올 가장 빠른 시기**와 그 인연의 성격, 기록 저장 상태
   - 사주가 처음이라면: 네 기둥·일간·오행·배우자 자리·이성의 별·운을 쉬운 말로 안내(접힘)
   - 사주 원국표: **시주 > 일주 > 월주 > 연주** 순서(전통 표기), 8글자를 큰 한자로, 글자 아래 쉬운 말 라벨(예: 편관 → '강한 책임감'), 이성의 별 ♥ 표시, 누르면 뜻 툴팁
   - 오행 분포: 목·화·토·금·수 개수 막대 + 많음/없음 해석
   - 성격·기질: 일간 중심 + 오행 분포 반영
   - **연애·배우자 분석**
     1. **인연이 찾아올 가장 빠른 시기**: 앞으로 10년 중 인연 가능성이 '높음' 이상인 첫 달(없으면 그 기간 가장 좋은 달) + 인연의 성격 3가지
        - 진중하게 만나 봐도 좋은 인연 / 끌림은 크지만 지켜볼 인연 / 스쳐 지나가기 쉬운 인연
     2. 한눈에 보기: 구조 유형(A~D)
     3. **♥ 만나게 될 이성, 이렇게 그려져요**: 외형·성격·하는 일의 결·**나이 차(연상/연하/동갑 추론)**·만남의 계기·인연이 닿기 쉬운 때를 한 문단 이야기로. 항목별 근거는 '항목별로 자세히 보기'에, 아래에 '참고용 추론'이라는 안내 문구
     4. **배우자 자리와 이성의 별, 그리고 인연의 때**: 지침의 A~E를 "닿게 될 인연은 ○○한 사람일 가능성이 있어요… 이런 인연은 ○○년에 닿기 쉬워요" 형식의 한 문단으로 합침. A~E 세부 근거는 접힘
     5. 나의 연애 스타일(연애 스타일·끌리는 외형·잘 맞는 사람·나에게 끌리는 사람), 조언, 정리(확인된 사실/추론/한계)
   - **연도별·월별 인연운**: 정확한 점수 대신 **막대그래프 + '매우 높음/높음/보통/낮음'**으로 대략적인 가능성 표시. 기간 선택(앞으로 10년 / 만 10세부터 10대·20대·…·80대) → 연도 선택 → 월별 타임라인 카드(예상되는 만남·조언·좋은 흐름·주의할 점·명리학적 근거). 지난 시기는 실제 지난 인연과 비교해 볼 수 있게 모두 표시(`/api/years`로 10년 구간 계산)
   - 공유·저장: 결과 요약 이미지 카드(1080×1350 PNG) 저장·공유, 글로 복사
   - **다른 AI에게 물어보기**: ChatGPT·Claude·Gemini 등에 붙여 넣을 질문을 복사(아래 참고), 계산 근거(전문가용, 접힘)
5. **내 기록** — 결과가 나올 때 자동 저장(같은 입력은 중복 저장하지 않음), 누르면 다시 계산해 보여 줌, 개별·전체 삭제. **이 브라우저(localStorage)에만 저장**되며 서버로 보내지 않음(최대 30건)

연애 중심 사이트이므로 직업·재물 해석은 제공하지 않습니다.

### 다른 AI에게 물어보기 — `src/lib/prompt/crossPrompt.ts`
복사되는 질문은 이 사이트의 목적(배우자상·인연 시기)에 맞춰져 있습니다.
- "당신은 40년 경력의 역술가입니다", "이전 질문 기록은 참조하지 말고 답해 주세요"로 시작
- 사주 전체 운세가 아니라 **만나게 될 이성**과 **인연이 들어오는 시기**에 집중하도록 요청
- 이 사이트의 분석 결과를 함께 주고, **동의하는 부분과 다른 의견을 사주명리학 근거로 나눠** 답하도록 요청
- 답변 형식: 한 줄 결론 → 배우자상 → 인연 시기 Top 3 → ✅ 동의 / 💬 다른 의견 → 조언
- 선택: 내가 원하는 배우자 조건을 적으면 사주상 배우자상과 비교해 달라는 질문이 추가됨

### 배우자궁·배우자성 분석 — `src/lib/reading/love.ts`
「배우자궁과 배우자성 분석 지침」을 따릅니다.
- **배우자궁(일지)과 배우자성(남 재성·여 관성)을 따로 평가**한 뒤 상호작용을 봅니다. 다른 기둥을 배우자궁의 대체물로 쓰지 않습니다(보조 정보로만 언급).
- 배우자궁 세력: 월령(+2/+1.5/−1.5) · 통근(지지별 최강 뿌리, 최대 +2) · 투간 · 생조(최대 +1.5) · 극(최대 −2) · 전체 오행 비율. 안정성: 충 → '흔들림 큼', 형·파·해·원진·강한 합거 → '변화 요소 있음'.
- 배우자성: 천간 투출 + **네 지지의 지장간 전부**에서 찾고, 위치·본기/중기/여기·통근·월령·생조·극제·합거·충을 기록. 정·편 혼재는 천간이나 본기로 뚜렷할 때만 판정.
- 지장간: 월률분야 표 사용. 지침 예시(본기 중심 표)와 대조한 결과 차이는 子壬·卯甲·午丙·酉庚·亥戊 다섯 '여기'뿐이며, 이 글자들은 '학파에 따라 제외' 표시와 함께 아주 약한 근거로만 반영(테스트로 대조 검증).
- 구조 유형 A~D(배우자궁 안정 여부 × 배우자성 유력 여부)는 분석의 출발점이며 길흉 분류가 아님.
- 배우자성이 없거나 약해도 결혼 불가·배우자 부재로, 일지가 약해도 배우자복 없음으로 단정하지 않음. "인연 없음"이라고 말하지 않음.
- **만나게 될 이성 추론**: "알 수 없어요" 대신 원국에서 보이는 단서로 외형·성격·하는 일의 결·만남의 계기를 추론하고, 아래에 '사주 상징으로 본 추론이니 참고만'이라는 안내를 붙임.
- **나이 차 추론(`inferAge`)**: 이성의 별이 놓인 기둥(연주 → 연상, 일주 → 동갑·또래, 시주 → 연하), 배우자 자리의 십성(인성 → 연상, 식상 → 연하, 비겁 → 동갑), 정관·정재, 신강약을 합산. 연상·연하 근거가 비슷하면 "나이 차가 있는 사람(○○ 쪽이 조금 더 유력)"으로 표시.
- 문장은 "긴장이 있을 수 있지만 좋고 나쁨을 정하지 않아요" 같은 얼버무림 없이, "내가 관계를 이끄는 쪽이 되기 쉬워요. 상대의 이야기를 충분히 들어 주면 관계가 훨씬 편안해져요!"처럼 결론과 조언으로 씀.
- 조사(이/가, 은/는 등)는 글자 받침에 맞게 자동 보정(`src/lib/josa.ts`).

## 실행 방법

```bash
npm install
npm test          # 계산·해석 검증 (102개 테스트)
npm run build
npm start         # http://localhost:3000
# 개발 모드: npm run dev
```

- Node.js 20 이상 필요. 개발·검증 환경: Node 26.13, Windows 11.
- AI 종합 해석(선택): `.env.local`에 `ANTHROPIC_API_KEY`를 설정합니다. 없으면 AI 기능만 꺼지고 나머지는 모두 동작합니다.
- **OneDrive 폴더에서 빌드할 때** `EPERM: operation not permitted, unlink '.next\...'` 오류가 나면, OneDrive가 빌드 폴더를 동기화 항목으로 바꿔 잠근 것입니다. `npm run clean` 후 다시 빌드하세요. 가능하면 프로젝트를 동기화되지 않는 폴더로 옮기는 것을 권장합니다.

## 아키텍처

계산과 해석을 완전히 분리했습니다. AI는 계산 결과를 입력으로만 받으며 원국을 바꿀 수 없습니다.

```
입력 검증 → ① 음양력 변환 → ② 시간대·태양시 → ③ 사주 원국 → ④ 구조 분석
        → ⑤ 대운·세운·월운 → ⑥ 연애운 점수(버전 관리) → ⑦ 규칙 기반 해석(근거 포함)
                                                     ↘ (선택) ⑧ AI 해석 — 서버가 원국을 재계산해 구조화 데이터만 전달
```

| 경로 | 역할 |
|---|---|

추가 독립 검증:
- **24절기**: 1900~2100년 전체 4,824개 절기를 독립 구현과 비교, 최대 차이 1.04분(2098년). KASI 발표 입춘 시각(2024·2025·2026)과 1분 이내.
- **일진**: 무작위 2,000일 독립 구현과 일치, 기준점 2000-01-01 戊午.
- **연·월주**: 무작위 3,000개 출생 시각(절입 ±3분 제외) 독립 구현과 일치.
- **음력 데이터 천문 검증**: 1950~2050년 음력 초하루 1,249개가 모두 한국시 기준 실제 삭(新月) 날짜와 일치, 윤달에 중기가 든 사례 0건.
- **점수 원칙**: 배우자궁 충은 항상 '변화의 계기(+)'와 '안정성 저하(−)'를 함께 기록, 같은 범주 다중 요소에 체감 가중 적용, 같은 월운도 원국에 따라 다르게 평가됨을 테스트로 확인.

> 코드가 오류 없이 실행된다는 사실만으로 정확하다고 판단하지 않기 위해, 위 비교는 모두 서로 다른 알고리즘·데이터 출처와 대조했습니다. 다만 한국 만세력 앱마다 기본 설정(자시·태양시·지장간)이 달라 앱 간 결과 차이는 생길 수 있으며, 설정별 비교표로 확인할 수 있습니다.

## 연애운 점수 (`love-score/1.0.0`)

- 기준 50점에서 5개 범주(배우자성 활성화, 배우자궁 작용, 관계 형성 요소, 지속성 요소, 불안정 작용)의 기여를 더하고, 대운·세운·월운 레이어별 합계도 함께 공개합니다.
- 합·충·형·파·해를 자동 가감점하지 않습니다. 신강약, 배우자궁이 원국에서 이미 합으로 묶여 있는지, 합의 결과 오행이 희기 방향 중 어디인지, 충하는 글자가 배우자성인지 등에 따라 반영값이 달라집니다.
- 같은 범주의 요소는 체감 가중(1, 0.6, 0.35, 0.2…)을 적용하고, 신살 기여는 최대 +4로 제한합니다.
- 인연 유형(A 진중 / B 지켜볼 / C 가벼운)은 끌림·형성·지속성·불안정 네 지표의 조합으로 판정하며 근거를 함께 표시합니다. 맨 위 '가장 빠른 시기'의 인연 성격 설명도 이 유형을 씁니다.
- 화면에는 점수 숫자 대신 막대와 단계(68점 이상 매우 높음 / 60 이상 높음 / 50 이상 보통 / 그 외 낮음)로만 표시합니다. 숫자 점수는 '다른 AI에게 물어보기'로 복사되는 질문에 들어갑니다.
- **가중치는 전통 해석을 바탕으로 설계한 값이며 실제 연애 데이터로 보정되지 않았습니다.** 점수를 통계적 확률로 해석하면 안 됩니다.

## 개인정보

- 로그인 없이 이용 가능. 출생 정보는 계산에만 쓰이고 저장·로그되지 않습니다.
- '내 기록'은 이 브라우저에만 저장되며 서버로 보내지 않습니다. 결과 화면이나 기록 목록에서 언제든 삭제할 수 있습니다. 공용 컴퓨터에서는 사용 후 '기록 전체 삭제'를 권장합니다.
- 배우자 조건 입력란의 내용은 서버에 저장되지 않습니다(AI 해석 요청 시에만 전송).
